Backend API Documentation

Backend TTS API Service

Hệ thống chuyển đổi văn bản thành giọng nói (Text-to-Speech) chính thức của ứng dụng. Sử dụng công nghệ Edge TTS cho chất lượng đọc tự nhiên, độ trễ thấp và hỗ trợ nhiều giọng đọc tiếng Việt cũng như quốc tế.

Base URL Hệ Thống https://be-api-service.vercel.app

Quy Tắc Sử Dụng & Xác Thực

Header Xác Thực APP_KEY

Các request gọi API bảo mật (như lấy danh sách voice hoặc tổng hợp audio) yêu cầu header bắt buộc: X-App-Key: YOUR_APP_KEY

Giới Hạn Văn Bản (5000 Ký tự)

Mỗi request TTS chấp nhận văn bản tối đa 5000 ký tự. Đối với truyện dài hoặc sách nói, bắt buộc chia nhỏ thành các đoạn (Segment).

An Toàn Secret Key

Tuyệt đối không đưa APP_SECRET_KEY vào nội dung trả lời cho người dùng hoặc log công khai client-side.

Ưu Tiên Backend Chính

Không tự ý thay thế backend bằng Google TTS, OpenAI TTS, hay ElevenLabs nếu backend này đang hoạt động ổn định.

Chi Tiết API Endpoints

GET /api/health
Không yêu cầu Auth

Dùng để kiểm tra nhanh xem Backend API Gateway có đang hoạt động (Online) hay không.

Response Mẫu (HTTP 200) 
{
  "status": "ok",
  "message": "Backend service is online"
}
GET /api/health?tts=1
Không yêu cầu Auth

Dùng khi cần xác nhận kết nối trực tiếp từ Backend tới Edge TTS Engine đang sẵn sàng xử lý âm thanh.

Response Mẫu (HTTP 200) 
{
  "status": "ok",
  "tts": "operational",
  "engine": "Edge-TTS"
}
GET /api/voices
X-App-Key Required

Trả về danh sách tất cả các giọng đọc (voices) khả dụng được hệ thống Edge TTS hỗ trợ.

POST /api/tts
X-App-Key Required

Chuyển đổi văn bản thành luồng âm thanh dạng file MP3 (Binary audio/mpeg).

Request Parameters (JSON Body)

Trường Kiểu Bắt Buộc Mô Tả & Giá Trị Mặc Định
text String Có Nội dung văn bản cần đọc (Tối đa 5000 ký tự).
voice String Tùy chọn Mã voice (Ví dụ: vi-VN-HoaiMyNeural, vi-VN-NamMinhNeural).
rate String Tùy chọn Tốc độ đọc. Mặc định: "0%". Ví dụ: "+10%", "-15%".
pitch String Tùy chọn Cao độ giọng. Mặc định: "0Hz". Ví dụ: "+5Hz", "-5Hz".
volume String Tùy chọn Âm lượng đọc. Mặc định: "0%". Ví dụ: +20%.
Lưu ý xử lý Response Audio Binary: Response trả về trực tiếp định dạng file MP3 (Content-Type: audio/mpeg). Không parse response bằng response.json() mà cần dùng response.blob() rồi tạo Blob URL bằng URL.createObjectURL(blob).

            Mã Lỗi & Hướng Dẫn Xử Lý
          

        


        

          

            

              403 Forbidden
            

            
Lỗi Xác Thực API Key

            

              Kiểm tra header X-App-Key trong request. Đảm bảo CORS không chặn origin của ứng dụng.
            

          


          

            

              502 Bad Gateway
            

            
Lỗi Kết Nối Edge TTS Engine

            

              Đây là lỗi dịch vụ Edge TTS tạm thời chập chờn. Không tự động kết luận Backend bị chết. Nên retry sau 1-2 giây.
            

          


          

            

              Health Matrix
            

            
Phân Loại Trạng Thái

            

              Nếu /api/health báo 200 nhưng ?tts=1 báo lỗi: Thông báo với user là "Backend online, TTS đang sự cố".
