Hướng dẫn cài đặt DNS trên iOS (iPhone / iPad)

Chỉ cần thao tác một lần duy nhất để chặn quảng cáo toàn bộ hệ thống

1

Tải Cấu Hình

Chọn file DNS mong muốn và nhấn "Tải Profile", sau đó chọn "Cho phép".

2

Cài Đặt Hồ Sơ

Mở ứng dụng Cài đặt (Settings) > Nhấn vào mục "Đã tải về hồ sơ" > Chọn Cài đặt.

3

Kích Hoạt DNS

Vào Cài đặt > Cài đặt chung > Quản lý VPN & Thiết bị > DNS và chọn tên DNS bạn vừa cài.
